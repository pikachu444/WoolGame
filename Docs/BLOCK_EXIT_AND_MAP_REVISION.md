# 블록 출구와 맵 개편

모바일 사용자 사진에서 좌향 블록이 화면 밖으로 거의 사라지고, 하향 블록은 하단 도구 영역 뒤로 내려가던 문제가 출발점이다. 이전 이동은 전체 0.62초 동안 회전 없이 작아져 선반으로 이동했다.

## 원본에서 확인한 행동

[원본 프레임과 타임코드](../Evidence/Research/2026-09-10/BLOCK_EXIT_REVIEW.md)를 기준으로, 좌·우 출구에서는 몸체와 화살표가 위로 회전하여 가장자리를 따라 이동한다. 하향은 보드 하단에서 왼쪽 또는 오른쪽으로 회전하고 측면을 따라 올라간다. 선반 아래를 수평으로 이동한 뒤 목표 슬롯 위치에서 다시 위로 돌아 들어간다. 원본의 큰 경계 폭발 효과는 확인되지 않았다.

## 반영한 변경

- 방향에 맞는 회전과 경계 이동을 공통 경로로 만들고, 실제 슬롯 도착 시각과 수집 시작 시각을 그 경로에 맞췄다.
- 블록을 화면 바깥이나 도구 줄 뒤로 보내지 않는다. 회전 중 커지는 사각형의 대각선과 그림자도 화면 안쪽으로 보정한다.
- 운반 중 크기는 원래의 86%로 유지하고, 짧은 눌림·접점 표시·작은 타격음으로 방향 전환을 읽기 쉽게 했다. 이 연출과 시간값은 가독성을 위한 자체 조정이다. 원본과 프레임 단위로 같다는 뜻이 아니다.
- 하향 우회는 블록의 좌우 위치를 기준으로 가까운 쪽을 택한다. 원본의 왼쪽·오른쪽 사례와 일치하지만 중앙 동률 등 정확한 분기 조건은 미확인이다.
- 이동 블록은 선반 UI 앞에서 보이며, 일시정지·실패 메뉴는 블록보다 앞에 놓인다. 포커스 정지에서는 모습과 게임 시간이 유지된다.

## 고양이와 배경

원본 3레벨도 고양이가 왼쪽 굽이에서 시작하고 용이 다가오면 아래쪽으로 이동한다. 진행률 숫자는 도주 조건으로 확정하지 않았다. 현재 구현의 시작·도주·최종 방어 지점은 경로에 연결되어 있으며, 이번 3판의 S형 경로는 원본 장면을 참고해 수정했다. 모든 좌표·시간·원본 레벨을 정확히 복원했다고 주장하지 않는다.

| 환경 | 원본에서 직접 확인한 레벨 | 이번 자체 10판의 배정 |
|---|---|---|
| 잔디·꽃·베이지 도로 | 3 | 1~3 |
| 축제 숲·크리스마스 소품·적갈색 도로 | 5 | 4~5 |
| 리본·연보라 바탕·흰 도로 | 7 | 6~7 |
| 눈 장식·청회색 도로 | 9 | 8~10 |

확인하지 않은 인접 레벨의 배정은 자체 구성이다. 배경·도로·선반·보드 색과 장식을 함께 바꾸며, 이전의 세 경로 반복은 서로 구분되는 열 경로로 바꿨다. 배경 변화와 별도로 각 판의 난이도 구성은 [스테이지 설계](STAGE_PROGRESSION.md)에서 근거·실제 배치·관찰 여유·선택 부담을 검토한다.
