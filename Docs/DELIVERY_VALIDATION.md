# WoolLab 검증 결과

실행 증거는 Windows 플레이어에서 수집했습니다. Android 실기기는 연결되지 않았습니다. 아래 실제 결과와 미실시 항목을 구분합니다.

## 구현 범위

- Unity URP의 WoolLab 한 장면. 세로 고정 카메라, 상단 생물·중앙 네 자리·하단 방향 블록.
- 4·4·6·10 용량과 같은 색 공급 합계 24 unit. 방향 막힘 판정, 선택 피드백, 탈출 이동, 슬롯 도착, 몸통 풀림·연결 실·코일 감김, 작업 자리 회수, 구조 성공.
- 정지·재개·다시 보기·0.5/1배 속도. 정지 메뉴의 선택적 소리·진동. 광고·과금·로그인·서버·analytics 없음.
- 화면 배경, 용과 고양이, 겹친 마디, 블록, 버튼을 교체했습니다. 원작 레벨 데이터를 옮기지 않은 4블록 시연입니다.

입력 검사는 물리적인 마우스 조작이나 Android 터치 실험이 아닙니다. Windows 프레임 간격은 GPU 실행 시간, Editor Profiler 측정값, Android 성능값과 다릅니다. 녹화는 readback·PNG 저장 부하가 있어 성능 측정에 사용하지 않았습니다.

## 시각 검수

실제 전체·뜨개 확대·풀림·구조 성공 화면을 직접 열고, 원작 V04 프레임과 같은 크기로 비교했습니다. 연결 실과 코일은 연속 프레임 및 실제 MP4 재생으로 확인했습니다. 비교 이미지의 SOURCE에는 원작 광고 영역이 포함되며 우리 화면에는 광고가 없습니다. 촘촘한 전체 제품 레벨 UI와 원작의 캐릭터 연출을 그대로 재현한 제품은 아닙니다.

마디는 직접 만든 둥근 겹침 geometry이며 마디당 1,152 triangles, 24개 합계 27,648입니다. 원래 400–900이라는 시작 범위보다 높지만 첫 모델보다 경량화했습니다. 최종 화면 전체의 GPU triangle/batch·메모리·GC 예산은 Android에서 아직 측정하지 않았습니다. SSAO는 기본 off 출발점에서 변경해 반해상도·강도 0.65·반경 0.16으로 사용하며, 그림자 atlas는 2048입니다.

시각적인 동등성을 숫자만으로 통과시키지 않습니다. 원작과 거의 같은 완성도라는 최종 사용자 수용 판정은 아직 없습니다. 새 캐릭터 표정과 성공 연출, 블록 표면의 부피감에는 원작과 차이가 남아 있습니다.

## 미실시

- Android 기기 설치·기동·실제 터치·앱 전환 10회.
- Android 15분 연속 실행, 발열, p95/p99, CPU/GPU 별 시간, 메모리와 GC 실측.
- 아내의 실제 기기 플레이 및 시각 만족도 확인.

기기가 없는 항목을 통과로 표시하지 않습니다. APK 서명·패키지·ABI·권한 검사 결과는 함께 제공되는 `Evidence/Android` 기록을 기준으로 합니다.

최종 재질: 닫힌 둥근 실 고리의 RefinedKnit normal/AO를 사용하며, 기본 8열로 화면상의 고리 가독성을 조정했습니다. 이는 문서의 시작 12–20열을 고정 사양으로 적용한 값이 아닙니다.

최종 녹화 기록: 16초 동안 원본 479프레임을 저장했고 저장 대기열이 찬 1회는 캡처를 건너뛰었습니다. 저장 오류는 0입니다. MP4는 실제 시간표를 사용한 540×1170·30fps·16.033초 영상입니다. 이 수치는 기기 게임 성능 결과가 아닙니다.
