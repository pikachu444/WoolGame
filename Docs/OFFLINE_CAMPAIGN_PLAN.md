# 오프라인 캠페인 구현 범위

2026-09-10 사용자 승인. 기존 개편과 조사 자료를 먼저 원격 커밋 04bbaed에 보존하고, 아래 범위를 구현한다. 사용자 논의가 이전 문서보다 우선한다.

## 제품

Godot 기반 개인용 오프라인 게임, 자체 제작한 10개 스테이지. 도전·자유 모드는 진행, 코인, 성장, 카드가 별도로 저장된다. 홈, 결과, 고양이 성장, 카드 10장을 제공한다. 서버, 순위, 팀, 광고, 결제는 연결하지 않는다. 사용자가 수용한 캐릭터 아트를 유지한다. 기존 76% 장면은 levels.gd와 이전 Evidence에 비교 자료로 남긴다.

## 행동과 개인용 기본값

관찰로 확인한 도주·방어·수집의 구분을 구현한다. 원본 내부 수치가 확인되지 않은 항목은 아래 개인용 기본값을 사용하며, 원본 확정 수치라고 주장하지 않는다.

- 다음 지점이 있으면 고양이가 0.7초 동안 도주한다. 도주 자체로 하트가 줄지 않는다.
- 마지막 지점에서는 0.5초 예고 뒤 화염을 내보낸다. 보호 상태가 아니면 하트 1개를 잃고 1초간 추가 피해를 받지 않는다.
- 보호막은 5초 유지 후 용을 몸통 두 마디 길이만큼 밀어낸다. 동결은 3초다. 각각 한 판에 한 번 사용된다.
- 여러 용은 고양이의 하트를 공유하며 피해 면역 중 중복 피해를 주지 않는다.
- 화면에서 공격을 구별할 수 있도록 머리는 경로상 90px 앞에서 멈추고, 100px 안에서 도주·공격 예고를 시작한다.
- 블록 출발 → 가로 선반 → 접점에서 실 풀림 → 감김 → 빈 슬롯 순서로 표현한다. 강화 12초 동안 안개와 화면 밖 실도 수집할 수 있다.
- 가득 찬 슬롯에서 8초 동안 수집이 진행되지 않으면 실패한다. 이 시간도 개인용 기본값이다.

## 진행과 경제

도전 모드는 300코인으로 시작한다. 첫 클리어는 50코인, 재클리어는 20코인이다. 슬롯 추가·강화·이어하기는 100코인, 제거·정렬은 75코인이다. 자유 모드는 도구와 이어하기가 무료이고 사용 횟수에 제한이 없다. 최대 슬롯 수는 두 모드 모두 8개다. 재도전은 무료다.

이어하기는 진행률과 남은 실을 보존한다. 사용 중인 슬롯의 남은 실은 보조 선반으로 옮겨 다시 선택할 수 있다. 하트는 회복되며, 용은 max(720px, 진행 속도 × 45초)만큼 후퇴한다. 초기의 280px 후퇴는 독립 검사에서 조작 여유가 부족해 확대했다.

시작 하트는 1개다. 3·6판의 첫 완료 후 각각 2·3개가 된다. 보호막은 2판 후, 동결은 7판 후 해금한다. 매 판 첫 완료마다 카드 한 장을 받는다. 결과 → 홈 → 다음 판으로 진행한다.

보상은 승리 순간 임시 파일에 기록·flush 후 교체하며, 마지막 유효 저장과 임시 파일로 복구한다. 실행별 정산 ID로 중복 보상을 방지한다. JSON 재로드 시 완료·카드 번호를 정수로 정규화해 성장과 재클리어 판정을 유지한다. 기존 progress.cfg는 보존하고 음소거 설정만 가져온다.

## 검증과 출하 기준

메인이 구현과 회귀 검사를 담당한다. 별도 규칙 검증자는 자체 해법으로 두 모드 10판, 피격·방어·수량·도구·복구·보상·저장을 검사한다. 별도 플레이 검증자는 실제 입력과 실패·이어하기·연속 진행, 원본과 같은 상황의 화면 및 정성적 느낌을 검사한다. 제품 코드는 메인만 수정한다.

독립 검증에는 후보 커밋과 패키지 해시를 명시한다. Windows와 Android의 내장 PCK가 같은지 확인한다. 자동 입력, 연출을 위한 상태 주입, Windows 실제 마우스 입력, Android 실기기 검증은 서로 구분해 기록한다. 검증을 막는 환경 조건은 합격 처리하지 않는다.
