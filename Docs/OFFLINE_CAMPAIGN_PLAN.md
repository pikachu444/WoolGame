# 오프라인 캠페인 실행 범위

2026-09-10 사용자 승인. 현재 브랜치에 기존 개편과 조사 먼저 보존한 뒤 새 개발을 진행한다.

## 제품

Godot, 개인용 오프라인10판. 서버/온라인순위/팀/광고/결제 없음. 도전/자유 모드 각각 저장. 홈, 결과, 성장, 카드10장. 현재 수용된 캐릭터 아트 유지. 기존76%장면은 비교용.

## 행동

경로와도주지점은레벨데이터. 고양이도주와HP피해를분리하고190px일괄반동을제거. 다음지점이있으면0.7초도주,마지막지점에서는0.5초예고후화염/방어/피해1,피해후보호1초. 무적5초후몸통2마디길이격퇴,동결3초,각판당한번. 이는미확인항목의개인용기본값이며원본의확정수치로표시하지않는다.

실수집은블록출발→가로선반→접점풀림→감김→완료슬롯비움. 화염/방어/수집효과구분. 강화는안개/화면밖수집제한해제.

## 진행

도전최초300,첫클리어50,재클리어20. 추가슬롯/강화/이어하기100,제거/정렬75. 자유보조기능무료무제한,재도전양모드무료. 이어하기는진행률/남은실보존,슬롯잔량을보조선반이동,하트회복,용후퇴.

시작1하트,3/6판첫완료뒤2/3하트. 무적2판후,동결7판후. 첫완료마다카드1장. 결과→홈→다음. 보상원자적저장,모드별분리,구저장보존/음소거만이관,새캠페인1판시작.

## 검증

구현담당과별도로규칙검증/실제UI플레이검증에독립에이전트각1명. 규칙검증은자체기대값/해법을만들어10판도구없이클리어와피격,수량,도구,복구,보상,저장검사. 플레이검증은정답demo외실제UI입력/오입력/연속입력/실패/이어하기/모드/저장,원본동일상황구도와정성평가. 후보커밋과패키지해시로판정하고수정후재검증. 제품코드는메인만수정. Windows및Android동일PCK검사,실기기검증범위명시.
