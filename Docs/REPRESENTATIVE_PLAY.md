# 원본 Level 2 대표 플레이 재구성

대상은 Wool Crush의 N3 영상 Level 2다. 화면만 비슷하게 만든 열 판을 더 늘리기 전에, 같은 배치에서 원본의 선택과 생존 보상이 이어지는 한 판을 검증한다. 캠페인 2판을 이 대표판으로 교체했고 나머지 9판의 데이터는 유지한다. 전체 캠페인의 난이도 곡선을 원본과 같게 복원한 결과는 아니다.

## 직접 확인하여 반영한 내용

- 6.80초의 0% 보드: 28개, 8색, 상하좌우 화살표, 세 가지 길이. 모든 블록의 선반 용량4·6·10을 실제 숫자로 확인했다. 총176가닥이다.
- 원본28개 출발 시각과 첫10개 선반 위치를 기록했다. 앞의 빨강6, 청록10, 주황10은 한 번에 끝나지 않는다. 중간에는 빨강6·청록5·주황2가 남은 채 네 번째 칸으로 다음 색을 고른다.
- 색의 공급을 블록 하나씩 나열하던 구조에서, 한 색을 여러 구간에 나누는 명시적 실 배열로 바꿨다. 블록별 수량과 전체 색 수량을 보존한다.
- b11 노랑4의 세 번째 수집에 주먹 표지가 연결된다. 큰 격퇴 후 빠르게 재접근하고 다시 일반 전진으로 돌아가는 원본 동작을 반영했다.
- b18 노랑4의 네 번째 수집에 감속 표지가 연결된다. 표지는 실제 색 수집으로 획득하며 정해진 시각에 자동 발동하지 않는다.
- 실을 감아 공격 범위 밖으로 밀어냈는데도 이전 예고가 피해를 주던 버그를 독립 재현하고 수정했다. 다시 접근하면 새 예고를 시작한다.

## 관찰과 추정의 경계

[원본 관찰 데이터](../Evidence/Rebuild/Representative/Reference/level2_replay_observed.json)와 [배치 데이터](../Evidence/Rebuild/Representative/Reference/level2_start_blocks.json)는 영상에서 읽은 값이다. 전체 숨은 실 배열, 원본 충돌체, 내부 속도 상수를 추출한 것은 아니다. 현재 실 배열은 관찰된 선반 잔량·선택 순서·능력 획득에 맞춘 재구성이다.

54px/s 일반 속도,40px의 개별 후퇴,1000px/1.7초 큰 격퇴와335px/s 복귀는 원본 위치·시간을 현재 화면 좌표로 옮긴 근삿값이다. 일반 감김의 후퇴 하한은 관찰한 중간 왼쪽 굽이로 두었다. 큰 주먹은 그 경계를 넘어 후퇴한다. 최종 고양이320px 이내에서는27px/s로 접근한다. 원본의 마지막 직선에서 관찰한 약13source px/s에 대응하며, 전환 거리320px는 추정값이다. 감속의6초·0.25배 중 배율은 추정값이다. 공격 중 정지한다는 초기 의심은 무수집 프레임 재검토로 철회했고 코드에 추가하지 않았다.

시작 보드는6.8초에서 읽고, 용·고양이의 활성 시작 위치는16.4초에서 읽었다. 영상의 입장 대기를 강제로 재생하지 않는다. 대신 첫 선택 전 최대10초 동안 보드를 읽을 여유를 주며, 유효한 블록을 고르면 즉시 움직인다. 이 부분은 제품 사용성을 위한 명시적인 보정이다.

## 검증과 남은 한계

원본 출발28회를 정상 게임 상태에 재생하고 선반 점유·능력 획득·클리어를 확인한다. 별도로 현재 보이는 색과 출구만 사용하는 여러 선택 속도와 다른 선택 정책을 검사한다. 화면 녹화는 정상 렌더러의 상태 재생이며 Windows에서 사람이 포인터로 완주한 영상으로 표현하지 않는다.

현재 Windows 앱은 정상 실행 로그와 GPU 렌더를 확인했으나 OS 화면 캡처가 검고 창 활성화가 실패했다. 재확인에서 Windows 잠금 화면이 직접 보였으므로 실제 창을 클릭하는 완주 검증은 진행하지 못했다. Android 실기기 터치 완주와 사용자의 재미 평가는 별도로 남는다. 자동 완주를 원본만큼 재미있다는 증거로 쓰지 않는다.

## 후보07 개발 측 결과

원본28회 입력을 같은 시각으로 재생해125.6초에 완료했다(원본 활성 구간124.033초). 첫10회 선반 위치,45·60초의R6/C5/O2,주먹과감속의 수집 단위가 일치한다. 전체 숨은 실 배열을 복원한 것은 아니므로 후반 일부 실감개 소진 시각은 원본보다 수초 빠르다.

마지막 선반 칸은 현재 노출된 미예약 실로 끝낼 수 있을 때 사용하는 가시 정보 전략에서0.8/1.2/2.4/3.2초 간격은55.7/60.3/77.1/94.7초에 완주했다. 최대 수집 공백은2.3/2.8/2.5/3.0초, 마지막 선택 후 자동 감기는 시간은4.7/4.7/2.9/2.9초였다. 눈앞에 일부 색이 있다는 이유만으로 마지막 칸을 긴 실감개로 채우는 기존 그리디 실패도 진단 결과에 보존한다. 모든 선택을 승리시키기 위해 판을 바꾸지는 않았다.

빌드 검사는 캠페인48/48, 스테이지2062/2062, 대표판367/367, 화면·저장147/147이다. UI 검사 종료 시 ObjectDB 객체2개 누수 경고가 남는다. APK 패키지·서명·정렬 검증을 통과했으며 기기 플레이 확인과 구분한다.

시각 검토에서 고양이 최종 위치와 일반 후퇴 범위를 수정했다. 보드 가로 점유율(원본 약89%,현재 약77%), 주먹 발동 전 머리 위치와 격퇴 경로의 일부 차이는 남는다. 현재 결과를 픽셀 일치나 원본과 같은 재미의 인증으로 표현하지 않는다.
