# 스테이지 추억 그림

2026-09-10 재미 개편. 카드 이름만 다른 반복 보상을 열 개의 실제 장면으로 교체했다. 원래 카드 ID, 최초 클리어 보상, 모드별 소유권과 저장 방식은 그대로 사용한다.

- 원본 자산: Rebuild/art/memory_cards_v1.png (1003 × 1568)
- 게임 리소스: Rebuild/art/memory_cards_v1.res
- 생성 방법: 내장 image_gen 도구, 기존 reference_cast.png 및 reference_details.png를 캐릭터 참고 이미지로 사용. 생성 후 픽셀 편집 없이 프로젝트에 복사했다.
- 생성 지시 요약: 주황색 코바늘 고양이와 친근한 주황색 용을 유지한 고품질 3D 뜨개 장면. 두 열, 다섯 행의 단일 카드 아틀라스. 글자와 로고 없이 열 장을 확실히 구분한다. 첫 만남과 빨간 실뭉치, 들꽃 왕관 산책, 통나무 다리를 건너는 작은 용기, 함께 두른 목도리, 무지개 실, 보라 리본으로 맺는 숲속의 약속, 안개 속 등불, 눈사람과 얼음꽃, 두 용 친구, 따뜻한 집에서 쉬는 마지막 장면을 순서대로 배치한다.
- 런타임: memory_cards.gd의 AtlasTexture로 각 장면 영역을 지정한다. 전체 장면에는 캐릭터용 녹색 제거 셰이더를 사용하지 않는다.

최초 클리어 결과는 얻은 그림과 카드 이름을 크게 보여 준다. 재도전 결과는 같은 장면을 보여 주되 새 카드 획득이라고 표시하지 않는다. 수집 화면에는 얻은 그림만 표시한다. 홈의 다음 추억 이름은 다음 보상의 작은 예고다.

이 변경은 보상 구별과 수집 동기를 개선하기 위한 것이다. 실제 재미나 장기 재방문 효과가 입증됐다는 뜻은 아니다. Rewards 스크린샷은 보상 프로필을 만든 시각 검토용이며 실제 플레이 완주 증거와 구분한다.
