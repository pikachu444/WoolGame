# 0.3.0 블록 출구·맵·스테이지 개편 검증

후보 소스 908c8efc4a53977f707ac1bb11f12e4e2d0901a6. 정확한 버전과 파일 해시는 [CANDIDATE.json](CANDIDATE.json), Windows ZIP과 APK의 내장 PCK 바이트 대조는 [package-integrity.json](package-integrity.json)에 있다. PCK는 351219ac1c7552ef9dfc4b755bd1e8b0bd452a1060ee731e8134ebee7b445090이다.

## 바꾼 동작과 화면

사용자 사진에서 옆/아래로 이동한 블록이 거의 사라지던 문제를 고쳤다. 원본 프레임에서 확인한 경계 회전→측면 이동→선반 아래 수평 이동→슬롯 진입을 적용하고, 몸체 크기와 화살표 회전·작은 접촉 표시를 유지한다. 모달은 이동 블록 위에 그려진다.

3판 S형 경로와 맵별 고양이 지점을 조정하고, 잔디·축제 숲·리본·겨울 네 테마와 서로 다른 열 경로를 넣었다. 독립 검토에서 발견한8판 제목/귀/하트 겹침은 제목을 상단으로 옮겨 해결했다. 열 판은 출구 방향·실 길이·색 수·안개·두 용을 단계적으로 다루는 수작업 배치다. 이후 시각 리뷰에서5판의 동일한 크기 블록 사이 용량이 구분되지 않는 정보 부족을 발견해,5판부터 하단에2/4/6을 표시하고 첫 안내에서 의미를 설명했다. [수량 표시 검토](Play/CAPACITY_REVIEW.md).

7판의6.2초 수집 공백은 독립 재현으로 원인을 확인한 뒤 안개는110px로 유지하고 용이 가림 구간을 통과하는 시점을 조정했다. 같은 전략의 공백은2.7초로 줄었으며 그 구간에도 즉시 감을 색이 남는다. 가려진 실의 색을 숨기고, 실제 노출 판정과 안개 시작/강화 표시를 맞췄다. 개발 솔버 결과만으로 재미를 승인하지 않고 별도 리뷰에서 공백 구간을 렌더했다.

## 확인한 근거

- 최종 전체 빌드: 캠페인40/40, UI92/92, 단계 설계1966/1966. [빌드 로그](Verification/Build). SCRIPT ERROR/ERROR는0건이다. UI 검사 종료 때 ObjectDB객체2개 경고가 남았으며 로그를 보존했다. 실제 최종 EXE의 실행·입력·정상 종료에서는 이 경고를 관찰하지 않았다.
- 단계 설계 개발 검사:60개 선택 전략 시나리오와 이전7판 입력 재생을 포함한다. [설계 방법·정량 결과·한계](../../../Docs/STAGE_PROGRESSION.md).
- 독립 규칙: 수량 표시 전PCK를 별도 경로에서 로드해 두 모드10판 진행·보상·저장·실 보존,1,760개 출구 경로,8슬롯/포커스/일시정지 전이,안개·강화·이어하기를 직접 실행했다. [독립 보고서](Rules/INDEPENDENT_BLOCK_EXIT_RULES.md). 수량 표시 후 최종 PCK는14개 소스와10판 정의/초기 상태를 직접 비교해 숫자3줄·안내문 외 규칙이 같음을 확인했다. [증분 검증](Rules/CAPACITY_DISPLAY_DELTA.md). 이는 headless 실행이며 실제 터치 플레이가 아니다.
- 독립 시각:10판의 배경/경로/고양이·제목 가독성,모달,7판 공백의 노출 색과 감기 진행을 검토했다. [맵·페이스 리뷰](Play/MAP_REVIEW.md).
- 최종 PCK의5개 출구 사례를 정상 select/advance로30fps,253프레임 재현했다. [영상](FinalMotion/block-exits-0.3.0.mp4), [출처와 해시](FinalMotion/PROVENANCE.json). QA 시작 상태를 구성한 재현이며 실제 마우스 입력 영상이 아니다. 기존 before/after/after-final 및 루트 block-exits-30fps.mp4는 수정 과정의 비교 기록이다.
- Windows 실제 포인터: 메인이 소스 실행에서 네 방향 출구·실 연결·실패·100코인 이어하기·일시정지를 조작했다. 수량 표시 전 배포 EXE에서 하향/우향 선택과 슬롯 진입·11% 수집·일시정지를 직접 확인했다. 수량 표시 후 최종 EXE는5판의 숫자와 실제 클릭·실 연결을 추가 확인했다. [실제 입력 범위와 캡처](Native/SESSION.md). QA3판 직접 진입이므로 정상 홈부터의 완주나 성장 후 난이도 확인으로 표시하지 않는다.
- APK0.3.0/code3: 실행 진입점,ARM64,서명v2/v3,16KB 정렬,Windows와 같은 PCK를 확인했다. Android 실기기 터치·성능·음향은 이번 환경에서 확인하지 않았다.

## 원본 분석과 남은 한계

[원본 영상 독립 조사](../../Research/2026-09-10/BLOCK_EXIT_REVIEW.md)와 [APK 실제 정적 분석](../../Research/2026-09-10/APK_ANALYSIS.md)을 반영했다. 원본은 Unity/IL2CPP이며 일부 레벨 자료와 환경/고양이/효과 구조를 읽었다. 화면 레벨과 내부 데이터의 연결표,충돌 알고리즘,정확한 원본 좌표·수치는 아직 복원하지 못했다. 네 테마의 대표 원본 장면을 확인했으며, 이번 열 판의 인접 테마 배정·배치·경제·난이도는 자체 설계다. 원본 APK나 추출 아트/코드는 공개 저장소와 배포물에 포함하지 않았다.

독립 시각 검토의 남은 개선 의견은 두 용의 몸통이 한 띠처럼 보이는 일부 장면,도로 가장자리에 걸리는 고양이 발/그림자,단순한 소품과 캐릭터 사이의 질감 차이다. 전체10판의 사람 플레이와 Android 실기기 평가는 아직 완료하지 않았다.
