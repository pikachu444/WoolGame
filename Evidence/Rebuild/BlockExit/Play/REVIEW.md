# 블록 탈출 이동 독립 시각 검토

2026-09-10 · 검토자 /root/play_reviewer · **판정: PASS_WITHIN_RENDERED_EXIT_SCOPE**

제공된 최종 다섯 경로에서 수정 전의 핵심 문제인 ‘옆·아래로 나간 블록이 사라져 다음 움직임을 볼 수 없음’은 해소됐다. 몸체와 화살표를 경계 회전부터 슬롯 도착까지 이어서 볼 수 있다. 검토 범위에서 새 P0/P1 시각 결함은 발견하지 않았다. 이는 아래 렌더링 증거에 대한 판정이며 모바일 실제 조작 전체의 합격을 뜻하지 않는다.

## 증거와 방법

- 사용자 모바일 사진 3장, before/after 네 방향 8개 시점씩을 먼저 비교했다. 초기 after는 최종 판정에서 제외했다.
- 최종 대상: [30fps 영상](../block-exits-30fps.mp4), [접점·도착 PNG와 기록](../after-final/recording.json). 540×1038, 8.433초, 좌향·우향·하향 왼쪽·하향 오른쪽·상향의 다섯 사례다.
- 영상은 초기 보드를 구성한 뒤 정상 select/advance를 30fps로 진행한 테스트다. 실제 마우스나 모바일 터치 영상이 아니다.
- 원본 영상의 시간축을 유지한 15fps 순차 프레임을 추출해 각 경로 전체와 도착을 비교하고, 최종 접점·도착 PNG 12장을 확인했다. 소리와 진동, 직접 재생의 체감 평가는 수행하지 않았다.
- 제품 코드와 UI 입력을 변경하지 않았다. [PROVENANCE.json](PROVENANCE.json)에 영상 및 최종 원본 파일 해시를 고정했다. 영상 SHA256: ab100b0d99bcd9aa0fe9daa446550fca7be995ef4d39decb0971da9afb2247f6.
- 원본 경로 근거는 별도 독립 조사 [BLOCK_EXIT_REVIEW.md](../../../Research/2026-09-10/BLOCK_EXIT_REVIEW.md)를 사용했다. 원본도 슬롯 입장 직전에 VIP/해제 줄을 지나며, 몸체·화살표가 함께 회전하고 운반 중 크기가 대체로 유지된다. 큰 벽 폭발은 확인되지 않았다는 조사 결과와 구분했다.

## 최종 관찰

| 항목 | 관찰과 판정 |
|---|---|
| 옆 벽 접촉 | 좌향·우향 모두 경계 안쪽에서 방향을 틀고 상승한다. 대각 회전 중에도 색과 몸체가 보이며, 수정 전처럼 화면 밖에서 작은 점으로 다시 나타나지 않는다. |
| 바닥과 측벽 | 하향 왼쪽·오른쪽 모두 바닥에서 가까운 측면으로 돌아 이동한 뒤 상승한다. 바닥 접점과 회전 몸체가 도구 버튼 위에 남는다. 원본 PNG에서 몸체와 도구 줄 사이 여유를 확인했다. |
| 방향 설명 | 출발 화살표가 옆 벽·바닥에서 실제 다음 방향으로 돌아간다. 선반 아래 수평 이동 후 목표 슬롯 x에서 위로 돌아간다. 표본에서 역방향 화살표나 경로 도중의 큰 순간 이동은 보이지 않는다. |
| 크기와 추적 | 운반 중 블록이 읽을 수 있는 크기를 유지한다. 최종 축소는 초기 56% 시안보다 덜하고, 기존 화면 가장자리의 작은 일부만 보이던 문제와 분명한 차이가 난다. |
| 접점 효과 | 얇은 접점 표시와 기울어진 몸체가 경계 위치를 알려 준다. 타격을 가장 잘 설명하는 것은 블록의 방향 전환이며, 접점 표시 자체는 절제되어 있다. 실제 모바일에서 효과 강도를 얼마나 느끼는지는 남은 확인이다. |
| 가림과 레이어 | 마지막 상승에서 VIP 글자를 잠깐 통과한다. 이는 원본에서도 관찰된 입장 방식이며 길게 가리거나 상단 코인·설정 HUD까지 올라가는 모습은 없다. 선반 아래 안내 문구 일부는 운반 블록이 잠깐 지나간다. |
| 슬롯 도착 | 다섯 사례 모두 슬롯에 도달한 뒤 실 감개로 바뀐다. 맞는 색 사례는 이어서 실이 용에 연결되고 감김이 진행된다. 도착 전에 블록이 사라진 채 기다리는 틈은 표본에서 보이지 않는다. |

좌·우·하향 순차 시트: [좌향](final-left-15fps.jpg), [우향](final-right-15fps.jpg), [하향 왼쪽](final-down-left-15fps.jpg), [하향 오른쪽](final-down-right-15fps.jpg), [상향](final-up-15fps.jpg). 각 시트는 행 우선 5×6, 2프레임 간격이며 각 사례가 끝난 뒤 남은 칸은 검정이다. 처음의 정지 프레임도 원본 영상에 포함된 준비 구간이다.

## 한계와 후속 범위

이번 증거는 일반 플레이 중 한 블록씩 이동하는 시각 경로를 확인한다. 동시에 여러 블록을 보냈을 때의 겹침, 일시정지·실패 모달 위 레이어, Android 터치와 화면별 클리핑·프레임률·소리·진동은 이 영상에 없으므로 통과로 확대하지 않는다. 배경·맵 테마는 후속 변경 예정으로 이번 판정 대상에서 제외한다. 경로가 빠짐없이 보인다는 개선은 확인했지만 모든 모바일 사용자가 정상 속도에서 충분한 충돌감을 느낀다는 결론까지 내리지 않는다.
