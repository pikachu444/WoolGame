## 독립 검토에서 발견해 수정 확인한 사항

1. 보드를 항상 z=5로 올리면 정지 블록이 수동 정지/실패 패널 위에 그려졌다. 구현 담당이 모달 때 보드를 아래로 되돌렸다.
2. 첫 수정의 state.playable() 조건은 포커스 자동 정지도 z=0으로 내려, 선반 진입 중 블록이 UI 뒤로 숨을 수 있었다. 실제 전이에서 z5→0 변화를 재현했고, 수동 정지/실패 조건만 레이어를 내리도록 수정 후 같은 검사에서 통과했다. [수정 전 재현](before-focus-layer-fix.json)
3. 안개가 없는 판도 reset_visuals 직후 안개 값이 1이라 잠깐 가려지는 초기화 불일치를 발견했다. 실제 안개 조건·승리·강화 상태로 초기화하도록 수정되어 최종 검사에서 잔여 관찰이 없어졌다.

## 판단 범위와 한계

독립 선택기는 구현의 hint 또는 witness를 해답으로 쓰지 않고 자체 장애물 기하와 현재 노출 색상·남은 슬롯 수요를 계산한다. 게임이 렌더링에 쓰는 이동 포즈를 읽되 모서리 회전과 화면 경계 비교는 검증기에서 직접 계산했다. 정지·실패 상태를 만든 경계 검사는 사람이 창을 조작한 플레이 증거로 쓰지 않는다.

안개는 동일한 fog_edge를 사용하고 경계 위 94% 덮임·아래 15px 흐림·숨겨진 실 무채색 처리 코드까지 확인했다. 실제 픽셀의 시인성, 원본과 비슷한 속도·눌림·효과의 만족감, 마우스 조작, Android 기기 실행은 이 독립 규칙 검사의 판정 범위 밖이다. 장면 진행 하네스는 음소거했으므로 오디오 출력 검증도 포함하지 않는다. 원본 하향 이동의 정확한 중앙 동률 방향은 확정 사실로 취급하지 않는다.

APK와 Windows ZIP 파일 자체 해시는 독립 계산했다. 두 패키지 내부 PCK 바이트 일치는 메인이 확인했다고 전달한 사항이며, 본 보고서의 독립 압축 해제 검증으로 주장하지 않는다. 현재 규칙 범위에서 추가 제품 수정 요청은 없다.
