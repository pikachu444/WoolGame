# 오프라인 캠페인 검증 기록

후보 소스: be25ca9569c006b2574143f73cc217e40644f581. 패키지 해시와 크기는 [CANDIDATE.json](CANDIDATE.json)에 기록했다. Windows ZIP과 Android APK의 PCK가 실제 Windows 입력 및 독립 규칙 검사 대상과 동일하다. [패키지 무결성](package-integrity.json)

## 구현

홈에서 시작하는 자체 10판, 도전·자유 모드별 진행·경제·성장·카드, 승리 순간 보상 저장, 결과→홈→다음 판을 구현했다. 도주·화염·피해·보호·동결·격퇴를 분리했고, 이어하기는 실과 진행률을 유지하며 보조 선반에서 재선택할 수 있다. 창이 비활성화되면 보드를 유지한 채 정지하고, 돌아오면 같은 상태에서 재개한다. 수동 일시정지는 별도로 유지한다.

## 검토와 실제 입력으로 고친 결함

1. JSON 재실행 후 완료 번호 타입이 달라져 보상이 중복되고 성장 능력이 사라지던 문제를 정수 정규화로 수정했다.
2. 초기 고양이·하트와 제목이 겹치는 경로를 수정했다. 홈의 용 몸통을 머리에 연결했다.
3. 화염이 캐릭터 뒤에 가려지지 않도록 공격 간격과 시작점을 조정했다. 도주·공격 예고·화염·하트 감소의 순서를 영상으로 확인했다.
4. 10판에서 이어하기 후 조작 시간이 부족하던 문제를 후퇴 거리 확대로 완화했다. 코인·실 수량을 유지하는 독립 검사도 재실행했다.
5. 포커스를 잃을 때 수동 메뉴가 자동으로 열려 다음 보드 클릭이 홈 버튼에 닿던 문제를 고쳤다. 별도 정지 상태, 끊긴 포인터 초기화, 복귀 시 재개를 구현하고 독립 24개 회귀 검사를 통과했다.

도주 자세가 미끄러지는 듯한 느낌과 위기 상황의 HUD 주변 혼잡은 추가 개선 사항으로 남았다. 원본 내부 동작과 모든 그림이 완전히 같다는 판정은 하지 않는다.
