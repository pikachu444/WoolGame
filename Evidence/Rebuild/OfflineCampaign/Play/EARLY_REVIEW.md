# 초기 독립 시각 검토

상태: 구현 중간 점검. 최종 합격 판정 아님. 확인한 게임 자체 프레임은 홈, 1판 0%/15초 무입력, 5판 0%다. 실제 UI 플레이는 미실행이다.

## 검증 환경

Windows UI 도구가 반환한 정확한 Godot 창을 선택했으나 검은 화면/활성화 실패가 발생했다. 사용자 환경 변수를 복원하자 게임 자체 렌더링은 정상이고 런타임 오류도 없었지만, Windows UI 캡처에는 시계와 날짜가 있는 잠금 화면이 표시됐다. 잠금 상태에서 입력을 보내지 않았다. 실제 클릭·모드 전환·성장·카드·종료·저장 판정은 잠금 해제와 후보 수령 후 진행한다.

분리 프로필: BuildWork/IndependentPlay/early-profile. QA 직접 레벨 진입과 --capture-dir를 사용한 화면이며 홈에서 직접 조작해 도달했다고 주장하지 않는다. 검토자가 실행한 자식 프로세스는 모두 종료했다.

## 현재 확인된 개선

해제 글자는 + 영역을 제외한 중앙에 놓이며 위 경로·중간 선반·아래 보드 경계가 읽힌다. 홈의 모드·코인·진행·시작 버튼은 한 화면에서 구분되고 글자 겹침은 없다. 이러한 시각적 확인은 버튼 실제 동작이나 저장 검증의 통과를 의미하지 않는다.

## 미검증

실제 선택, 수집 연결 효과의 움직임, 도주·피해·방어의 인과, 실패·이어하기, 10판 직접 진행, 모드 분리, 보상·종료·재접속은 미검증이다. 규칙 검증 에이전트의 자동 solver 완주는 별도의 규칙 증거다.
