# 실제 Windows UI 검증 중간 상태

후보: 114e7f3e8e21b3dc072277b1ecc6266bd24790a9. PCK SHA-256 685155149327a4d061b6d8a1f03be065332208804ae5513acbe3c7c9a7f9c56e. 새 프로필 BuildWork/IndependentPlay/final-profile. 정상 EXE 실행 후 홈에서만 시작했으며 --demo/--level/내부 상태 변경/저장 수정은 사용하지 않았다.

## 직접 확인한 것

- 실제 Windows UI 창에서 모드와 1판 시작 버튼을 눌렀다.
- 막힌 아래 블록을 누르자 “화살표 앞을 먼저 비워 주세요”라는 이유 안내가 나왔다.
- 열린 빨강·초록·노랑 블록이 가로 실감개로 이동했고, 해당 색의 연결실과 접점 발광, 수량 감소, 빈 슬롯 복귀를 관찰했다.
- 정상 선택 중 고양이가 아래 경로로 이동하고 하트1을 유지하는 장면이 실제 게임에서 나타났다.
- 도전 모드 실패 후 100코인 이어하기를 명시적으로 눌렀다. 코인300→200, 진행7%와 남은 보드 유지, 하트 회복과 용 후퇴를 확인했다.
- 홈에서 자유 모드로 바꾸자 자체300코인과0/10진행이 보였다. 도전의200코인과 분리된다.
- 자유 모드40% 실패 뒤 무료 이어하기를 명시적으로 눌러 같은40%와 남은 보드로 복구했다. 이후 직접 선택으로55%까지 진행했다.
- 실제 UI 화면은 기본540×1038 게임 내용과 Windows 제목 표시줄을 포함한다. 버튼·블록은 해당 창의 새 스냅샷 좌표로 클릭했다.

## 아직 확인하지 못한 것

첫 클리어, 결과→홈→2판, 성장/카드 해금, 종료·재실행, 코인 부족, 슬롯 포화, 다수 실의 동시 추적, 후반10판 직접 완주는 아직 미검증이다. 규칙 에이전트의 자동검증 및 패키지 렌더링 캡처와 혼동하지 않는다.

## 검증 환경 문제와 조치

초기에는 Windows가 잠겨 있었고 사용자 해제 후 실제입력이 가능해졌다. 한 차례 검은 무제목 창이 게임 앞에 나타난 뒤 게임이 포커스 상실로 일시정지됐다. 메인은 외부 프로세스 실행을 중단했다.

실제 행동 간격은 주로7.7~14초이며 sky 호출 자체는0.3~1.8초다. 도구 왕복/모델 판독 시간에 용이 전진하므로 이로 인한 실패를 정상 인간 플레이 난이도 결함으로 판정하지 않는다. 위험을 본 뒤 다음 선택 사이 실패/일시정지 모달이 생기면 기존 블록 위치가 홈/재도전 버튼과 겹쳐 의도하지 않은 종료가 발생했다. 같은 과정을 무한 반복하지 않고, 위험 구간에서는 선택을 멈추고 모달을 새로 관찰한 뒤 무료 이어하기를 누르도록 바꿨다.

마지막 정상 관찰은 자유 모드 홈0/10이었다. 이후 캡처가 검정이며 activate_window가 “failed to activate captured window”로 실패했다. 정확한 반환 창을 재선택하고 한 차례 재시도해도 실패하여 입력을 중단했다. 이번에는 잠금 화면 시계가 보이지 않아 재잠금으로 단정하지 않는다. 부모가 별도 세션에서 환경과 관찰 객체 문제를 확인 중이며 게임 창/PID87312를 유지한다.

접근성 트리에는 Godot Engine 영역과 Windows 제목 표시줄의 최소화/최대화/닫기만 있고 게임 안 버튼은 노출되지 않았다. 따라서 게임 화면의 시각 관찰과 좌표 입력을 사용했다.

실제 입력 로그와 캡처: [UI-114e7f3/actions.json](UI-114e7f3/actions.json).

## 재잠금 원인 확인

부모가 같은 프로필의 임시 ANGLE 비교 실행 창을 캡처했을 때 Windows 잠금 화면 “3:10 / 9월10일목요일”이 직접 표시됐다. 잠금 상태에서 기본 렌더러와 ANGLE 모두 Not Responding/창 활성화 실패를 보였으므로, 이번 검정 캡처와 응답 중단 표기를 게임 결함으로 확정할 수 없다. 실제 UI 검증 중 Windows가 다시 잠긴 사실이 확인됐다. 부모는 원래 검증 프로세스PID87312만 종료했고, 현재 비교용 임시 실행을 관리 중이다. 제품 소스는 변경되지 않았다. 사용자에게 잠금 해제 및 원격 연결 유지가 요청됐으며 해제 전 추가 입력을 보내지 않는다.
