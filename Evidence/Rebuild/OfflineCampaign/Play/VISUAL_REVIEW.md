## 이벤트 연속성

11초 `encounter-staged.mp4`(540×1038,30fps)를0.25초 간격 개요와 상세 프레임으로 검토했다. SHA-256: `9a309af44b43806f895f2aae20393d61865e85437754a5d5eaed15725cc90ed8`. 초기 조우 거리만 배치한 후 게임의 도주·공격 전환을 렌더링한 영상이다.

- 1.75→2.60초: 고양이가 왼쪽 굽이에서 아래 경로로 연속 이동하고1하트를 유지한다.
- 5.75→6.30초: 마지막 위치 앞에서 용이 멈추고 ! 공격 예고가 나타난다.
- 6.50→6.75초: 용 입에서 고양이로 주황 화염이 이어지고 하트가3→2로 바뀌며 붉은 피해 반응과 노란 보호 원이 나타난다.
- 7초 이후: 보호 상태를 거쳐 다음 공격 예고가 이어지고 마지막에는 실패 선택 화면이 나온다.

이 범위에서는 고양이가 왜 이동하고 언제 공격받았는지가 읽힌다. 원본의 미확인 정확 수치가 검증됐다는 뜻은 아니다. [선택 프레임과 범위](encounter-114e7f3/manifest.json). 오디오·진동은 정밀 검증하지 않았다.

## 남은 P2와 실제 플레이 검증

도주 중 고양이의 서 있는 자세가 유지되어 빠르게 미끄러지는 인상이 남는다. 위기 시 용의 뿔·몸통이 HUD 뒤로 지나가 배경이 혼잡하다. 결과의 새 카드가 이름 위주로 표현되어 수집 화면의 그림과 더 직접 연결할 여지가 있다. 9판 시작은 두 용 머리가 같은 줄에 가까워 움직임에서 두 위협이 분리되는지 실제 플레이로 확인해야 한다.

Windows 잠금 해제 이후 실제 UI로 막힌 블록 안내, 색 선택과 감김, 고양이 도주, 도전 유료 이어하기, 자유 무료 이어하기와 모드별 잔액을 확인했다. 통신·판독 간격과 모달 출현으로 의도하지 않은 홈 복귀가 발생했고, 이후 검정 캡처/창 활성화 실패로 입력을 중단했다. 현재 환경을 부모가 확인 중이다. 아직 첫 클리어·저장 재실행·10판 직접 완주가 확인되지 않았으며, 시각 판정으로 대체하지 않는다. 상세 실제 범위는 [UI_SESSION_STATUS.md](UI_SESSION_STATUS.md), 입력 로그는 [UI-114e7f3/actions.json](UI-114e7f3/actions.json)에 있다.

환경 정정: 부모의 별도 ANGLE 비교 창 캡처에서 Windows 잠금 화면이 직접 확인돼, 실제 UI 검증 도중 재잠금이 발생했음을 확인했다. 잠금 상태에서 두 렌더러 모두 응답 없음/활성화 실패였으므로 이를 게임 결함으로 확정하지 않는다. 재개 전까지 입력을 중단하며 시각 검토와 실제 완료 범위는 기존대로 구분한다.
