# 개발 중 연출 검토

이 폴더는 수정 과정의 캡처다. 최종 PCK 화면은 ../Visual-114e7f3에 있다.

encounter-staged.mp4는 경계 상태에서 시작해 실제 시간 규칙으로 렌더링한 11초 영상이다. 첫4초는 도주, 이후7초는 마지막 지점의 예고·화염·피해다. 실제 마우스 플레이가 아니다. 독립 판독과 영상 해시는 ../Play/VISUAL_REVIEW.md에 있다.

encounter-timing.log의 종료 시 리소스 경고는 해당 캡처 하네스가 관찰용 신호 클로저를 해제하지 않고 종료한 개발 기록이다. 후보의 capture_encounter.gd에는 관찰 신호 해제를 추가했다. 최종 규칙·씬 통합과 최종 PCK 캡처는 별도로 재검증했다.
