# 원본 N3 Level 2 대표판 독립 규칙 검증 계획

현재 단계: geometry 예비 검토 완료. 이동 속도·초기 위치·감김 값이 고정되기 전의 행동 결과를 최종 증거로 사용하지 않는다. 검증 담당은 제품 소스와 Windows 입력을 변경하지 않는다.

## geometry 확인 결과

관찰 원본은 Reference/level2_start_blocks.json의 28블록·8색·방향·시각 bbox다. 입력 자체는 원본 288×640 프레임에서 관찰한 ±2px 추정이며 collider 측정이 아니다.

가로·세로 모두 1.8배, x=296+(source_x-144.5)×1.8, y=599+(source_y-293)×1.8로 옮긴 현재 블록이 반올림 최대 0.5px 이내로 일치한다. 원본 시각 bbox와 원본 깊이를 12/1.8px로 가정해 보정한 bbox로 각각 독립 계산한 막힘 관계가 state.blockers와 전부 같다. 최초 열린 출구는 b01,b02,b03,b05,b06,b10,b11,b12,b17,b18,b19,b23,b24,b25,b27,b28의 16개다.

긴 블록을 포함해 28블록×8슬롯의 224경로를 검사했다. 각 경로 61시점과 구간 접점에서 몸체·그림자의 회전 모서리, 화면·하단 도구 줄 경계, 90도 회전과 도착 위치가 통과했다. [예비 결과](geometry-preliminary.json)와 [로그](geometry-preliminary.log)를 보존한다.

보드의 1.8배와 상단 경로의 1.9배는 서로 다른 영역 변환이다. 이 검사는 전체 화면이 하나의 등비 변환이라는 근거가 아니다. 원본 collider 및 미관찰 블록 용량·실열의 완전한 동일성도 주장하지 않는다.

나머지 9판은 기준 커밋 8718affc22bea206ddb5af8acaf44a3aee02a3d0과 정의가 동일하다. 실제 reset 결과의 기본값 pitch44, winding_interval0.46, unwind_duration0.46, clear_duration0.52, head_recoil4, initial_head_fraction0.34도 같다. 새 palette는 8색이며 기존 6색에 C/M 색을 추가했다.

## 고정 후보에서 수행할 행동 검사

1. 수집 이벤트 직전 head와 상태 갱신 직후 head를 짝지어, 각 수집이 전진을 만들지 않고 실제 뒤로 이동하는지 확인한다. recoil_floor보다 head가 작은 경계도 별도로 확인한다. 감김 없는 정상 추격 구간에서는 실제 전진을 확인한다.
2. 블록 용량만큼의 수집 이벤트·잔량·용별 실 수량, 수집별 후퇴 합, 마지막 감김과 clearing 시작 및 슬롯 해제 시점을 연결한다. 화면의 풀림 duration과 슬롯 fade가 해당 판 설정을 읽는지도 확인한다.
3. 도착 전 수집 금지와 겹친 입력의 슬롯 선점, 정지 동안 감김·후퇴 동결을 대표 한 건씩 확인한다. 기하 전체 회귀를 대규모로 반복하지 않는다.
4. 현재 보이는 색과 출구 기하만 사용하는 독립 두 방식으로 정상 성장 상태의 대표 2.4/3.2초 판단을 시험한다. 같은 색의 가시 실이 없는 블록을 한 번 먼저 고른 뒤 실제 만회 경로를 비교한다. 구현의 전체 yarn_order·witness·choose는 선택 해답으로 사용하지 않는다.
5. 성공뿐 아니라 패배 시각·수집량·가득 찬 슬롯·마지막 실제 수집 시각을 남겨, 너무 늦은 판단의 패배와 진행 중 잘못된 정체 패배를 구분한다. 원본에서 확인한 동작과 아직 추정/자체 작성인 값을 구분한다.
6. 실제 실행에 기록한 제품 해시와 고정 후보를 대조한다. 소스 검사와 패키지 검사 담당의 근거를 혼동하지 않는다.

실행은 Godot headless와 windowsHide:true로만 수행한다. 정량 결과가 사람의 재미나 원본과의 시각적 동일성을 대신하지 않는다.
