## 확인한 동작

효과 자체를 분리하기 위해 기존에 노출된 청록 실 1가닥에 검증용 표지를 달았다. 실의 색·순서·총량은 바꾸지 않고 정상 select→도착→감김으로 능력을 얻었다. 이 표지는 원본의 노란 실 배치를 재현한 것이라고 주장하지 않는다. 실제 스테이지 표지 연결은 별도 확인했다.

| 구분 | 결과 |
|---|---|
| 획득 조건 | 시간만 흘리거나 다른 색을 선택하면 발동하지 않음. 표시된 실이 실제 수집될 때 해당 unit_id의 이벤트가 정확히 1회 발생 |
| 시간 독립성 | 시작 시각0초와200초 모두 정상 선택 후0.57초에 발동. 원본 영상의 절대 시각에 맞춘 자동 발동이 아님 |
| 격퇴 | 1.7초 동안2016.799→1016.799의 경로 거리1000 역진. 0.85초 중간값1516.799 확인. 정지하면 시간·위치 동결 |

| 실제 표지 연결 | 현재 스테이지의 노란 unit54에 repel, 노란 unit152에 slow가 지정되어 reset 결과에 그대로 들어옴 |

## 저장과 검토 한계

현재 제품에는 진행 중 State를 저장했다가 복구하는 API가 없다. snapshot의 실 목록을 JSON으로 직렬화했을 때 소비한 표지가 돌아오지 않는 것과, 실제 continue_run에서 재발동하지 않는 것은 확인했다. 앱을 종료하고 같은 진행을 불러오는 저장/복구가 통과했다고 주장하지 않는다. snapshot의 dragon 정보도 slow_until 같은 효과 복구 필드를 포함하지 않으므로, 향후 중간 저장 기능을 만들면 별도 계약과 검증이 필요하다.

원본 b11의 세 번째 노랑 감김·b18의 네 번째 노랑 감김에서 실제 표지를 얻는지는 아직 전체 리플레이하지 않았다. unit54/152 연결 확인과 그 원본 대응 시점 확인은 다른 검사다. 최종 스테이지 배열과 초기 위치가 고정되면 리플레이 범위에서 다룬다.

1000px 역진,335px/s 복귀,감속0.25배는 구현에 설정된 값의 일관성을 검증한 것이다. 원본의 정확한 상수라고 인증하지 않는다. 원본 관찰과 추정의 구분은 reference 담당 근거를 따른다. 픽셀 효과·화염의 느낌·실제 조작감은 이 headless 단위 검사의 판정 범위 밖이다.
