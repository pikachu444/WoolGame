# 털실 구조대

Godot 기반 [Rebuild](Rebuild/README.md)가 현재 개발 대상입니다. 개인용 오프라인 10판 캠페인, 도전·자유 모드, 고양이 성장과 카드 수집을 구현했습니다.

- [원본 조사 보고서](Docs/WOOL_CRUSH_RESEARCH_2026-09-10.md)
- [독립 조사 검토](Evidence/Research/2026-09-10/INDEPENDENT_RESEARCH_REVIEW.md)
- [합의한 구현 범위와 개인용 기본값](Docs/OFFLINE_CAMPAIGN_PLAN.md)
- [현재 검증 범위](Evidence/Rebuild/OfflineCampaign/ACCEPTANCE.md)

Windows ZIP과 Android APK는 Rebuild/tools/build.py로 생성합니다. 원본의 특정 진행 장면을 복원했던 세 퍼즐과 UnityProject는 이력 자료입니다. 사용자와 합의한 범위 및 조사 결과가 이전 설계보다 우선합니다.
