# 털실 마스터 — Wool Crush 원작 분석

2026-09-08 / 대상 식별을 바로잡은 재기획판. 개발 코드는 작성하지 않았다.

## 1. 대상 정정

대상은 사용자가 첨부 이미지로 확정한 **털실 마스터 / Wool Crush**, Android `wool.match.color.sort.jam.puzzle`, iOS `6743385713`이다. 현재 개발사 표시는 Astrasen Global이다. 이전의 `wool.master.screw.match.coloring`은 별도 게임이다. 그 게임의 리뷰·이미지·레벨을 이번 원작의 증거로 사용하지 않는다. 과거 자료에 Mirror of Ember 또는 Snap Brain Games가 등장해도 이름만으로 제품을 합치지 않는다. [G1,A1]

기존 10개 문서는 `archive_wrong_reference/`에 보존했다. 현재 루트 문서가 유효하다. Unity/URP, 독립 Core, offline, solver 인증, 아트 우선 검증은 계승한다. 물체 회전·주문 2개+보관 5칸·동일색 3단위·그림 완성은 제외한다.

## 2. 사실과 설계의 구분

- **관찰:** 이미지·영상·페이지에서 직접 본 내용. 해당 버전과 관찰 구간에 한정한다.
- **강한 추론:** 여러 근거에 잘 맞지만 내부 구현을 직접 확인하지 못한 설명.
- **가설:** 다른 구현도 같은 화면을 만들 수 있는 미확정 설명.
- **우리 게임의 설계 결정:** 원작 사실이 아닌 구현 계약.

신뢰도·전체 출처는 [11_EVIDENCE_MATRIX.md](11_EVIDENCE_MATRIX.md), 이미지와 프레임은 [12_VISUAL_REFERENCE_INDEX.md](12_VISUAL_REFERENCE_INDEX.md)에 있다. 검색으로 찾은 영상 제목을 실제 시청으로 계산하지 않는다.

## 3. 실제 핵심 loop

**관찰:** 위에는 길을 따라 움직이는 뜨개질 용과 구조 대상, 중간에는 실타래 자리, 아래에는 화살표가 붙은 길이가 다른 블록들이 있다. 하단 블록을 선택하면 밖으로 이동해 중앙 실타래가 된다. 용 몸통의 같은 색에서 실이 연결되고, 감기는 동안 숫자가 감소한다. 완료된 실타래는 사라져 자리가 빈다. [U1,V1,V4]

## 5. 작은 실제 배치의 추상화

V1 약 00:02의 보이는 다섯 블록을 명명했다. 레벨 전체 초기 데이터의 복원본은 아니다.

| ID | 색·방향 | 상대 위치 | 탈출 blocker 후보 |
|---|---|---|---|
| Y1 | 노랑 → | 윗줄 오른쪽 | 없음 |
| Y2 | 보라 → | 윗줄 가운데 | Y1 |
| Y3 | 주황 ↑ | 왼쪽 긴 세로 | 없음 |
| Y4 | 보라 ← | 아랫줄 왼쪽 | 없음 |
| Y5 | 노랑 ← | 아랫줄 가운데 | Y4 |

**강한 추론:** `Y1 → Y2`, `Y4 → Y5`. 초기 selectable 후보는 Y1/Y3/Y4. 시연은 Y1,Y2,Y3,Y4,Y5 순이다. 막힌 블록에 대한 반복 입력 실험까지 한 것은 아니다.

전체 게임은 **방향성 공간 제약 + 제한된 작업 실타래 + 시간/노출 조건이 있는 색 자원 소비**로 설명한다. 고정된 하단 블록은 제거 DAG로 표현할 수 있지만 공급 장치·새 블록·시간·용 이동을 포함한 전체 상태에는 DAG 하나로 부족하다. renderer 픽셀 가림만으로 selectable을 정한다는 근거는 없다.

## 8. 조사 한계

핵심 loop와 시각 방향은 새 대상의 근거로 교정했다. **5개의 독립 실플레이 출처, 실제 후반 전체 레벨, 모든 부스터/실패 경계의 확정은 미충족이다.** YouTube 일반 영상·Shorts가 이 브라우저에서 재생 시각 0에 머물러, 재생 가능한 공개 기사 MP4를 분석했다. 링크를 찾았다는 이유로 시청했다고 기록하지 않았다.

시각 프로토타입은 시작할 수 있다. 원작의 미확정 내부 규칙은 02에서 독자 설계로 명시한다. 후반까지 역설계가 완료됐다고 주장하지 않는다.
