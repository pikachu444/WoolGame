# 제품 사양 — 솜길 구조대

2026-09-08. 털실 마스터(Wool Crush)의 재미와 미감을 참고하는 개인용 Android 게임. 이하 우리 게임의 결정이다.

## 목적과 핵심 경험

아내가 광고·과금 없이 귀여운 뜨개질 생물을 보고, 색과 방향을 판단하며 실을 풀어 내는 게임이다. 첫 제품은 **상단 구조 장면 / 중앙 4자리 작업대 / 하단 방향 블록**의 구도를 유지한다. 어려운 선택은 있어도 구매를 요구하지 않는다.

## 기본 사용자 흐름

앱 열기 → 이어하기 또는 레벨 선택 → 방향 블록 선택 → 감김과 구조 → 성공 반응 → 다음 레벨. 첫 실행부터 게임을 시작하고 로그인·약관 팝업·상점·출석 보상으로 막지 않는다. 정상 첫 실행에 필요한 모든 콘텐츠가 APK에 들어 있다.

| 화면 | 책임 |
|---|---|
| 게임 | 생물·작업대·보드. 되돌리기/계속 감기/일시정지/힌트 |
| 레벨 선택 | 완료/현재/새 레벨 구분, 재플레이 |
| 작은 도감 | 독자 용·구조 동물의 완성 모습, 짧은 반응 재생 |
| 설정 | 생각/흐름 모드, 속도, 소리·진동·색 심벌, 품질 |

## 유지할 것 / 바꿀 것

유지: 뜨개 마디, 강한 색 구분, 탈출 방향 제약, 크기별 수용량, 미완성 실타래의 공간 압박, 연결 실과 감김, 구조 대상의 귀여움.

개선: 기본 생각 모드, 무료 무제한 undo, 항상 가능한 일시정지, 명시적인 남은 용량, 다음 공급 색 미리보기, 부드러운 실패, 성공 시 눈웃음/인사, 레벨 반복 관리.

다음 색 미리보기는 현재 capture 가능 영역 밖의 다음 3개 색 구간과 분량을 보여 준다. 색을 미리 안다고 즉시 수집할 수 있는 것은 아니다. 생각 모드와 함께 정보 불공정을 줄이되 순서·공간 퍼즐을 유지한다.

## 완전히 제외하는 것

광고 SDK/배너/전면/보상형 광고, 광고로 자리 확장, IAP, 코인 판매, battle pass, 구독, 가챠, 로그인, analytics, 원격 설정, 서버, 온라인 인증, 에너지·목숨 충전 대기. 광고 제거를 산 뒤 다른 광고가 남는 상품 구조 자체가 없다.

기본 4자리로 모든 정상 레벨의 해답을 인증한다. 자리 +1은 무료 편안하게 옵션이며 상품·재화가 아니다. 원작에서 확인되지 않은 shuffle/undo 동작을 그대로 복제했다고 설명하지 않는다.

## 오프라인·저장·접근성

- 진행/설정/현재 레벨 snapshot을 로컬 저장. 임시 파일 후 원자적 교체, 최근 정상 backup 보관.
- background 진입 즉시 논리 시간 정지. 복귀해도 자동 위험 진행 없음.
- 색 ID별 선택 심벌을 블록·실타래·대응 몸통 구간에 일관되게 표시한다. 화살표가 이미 방향 정보를 담으므로 색 심벌은 작은 별도 badge로 둔다.
- 일반 버튼 터치 영역 48dp 목표. 조밀한 보드는 확대 보기 또는 선택 확인으로 오탭을 줄인다. 화면 한 픽셀 노출을 합법 선택으로 강요하지 않는다.
- 설정의 글자 크기와 별개로 남은 용량 숫자는 실제 중급 휴대폰에서 읽히는지 확인한다.
- 음악·효과·진동은 따로 끌 수 있다. 통화나 앱 전환 때 소리/시간 중단.

## 현실적인 첫 완성 범위

**24레벨, 마디 family 3종, 독자 머리 3종, 구조 동물 3종, 배경·경로 4종.** 첫 번째 결과는 이 수량이 아니라 한 개의 고품질 Visual Slice다. 그 다음 6레벨로 재미와 반복감을 검증한 뒤 24개로 확장한다.

수백 개 모델을 만드는 문제가 초기 필수 과제가 아니다. 이 원작의 표현 단위에 맞춰 소수의 높은 품질 마디/캐릭터와 다양한 보드를 조합한다. 모델 공급 도구를 게임보다 크게 만드는 일을 피한다.

## 수용 조건

광고 없이 비행기 모드에서 설치 후 모든 기본 기능 실행, 강제 종료 후 진행 복원, 기본 자리·지원 0 인증, 원작과 비교 가능한 뜨개 표면/감김, 13의 Android 성능 조건. 아직 구현·기기 검증을 수행한 것은 아니다.
