# Wool Master 3D 역설계 보고서

조사 기준일: 2026-09-08 · 문서 상태: 공개자료 분석 v0.9 / 영상 동작 검증 미완료

## 1. 결론과 조사 한계

이 게임의 중심은 **3D 구조에서 제거 가능한 털실을 찾아 색이 지정된 수집 공간으로 보내고, 제한된 임시 보관 공간을 관리하면서 별도의 그림을 완성하는 경험**이다. 단순한 자유형 3-match로 요약하면 현재 제시되는 스풀 색과 구조적 접근 순서가 만드는 난이도를 놓친다. 공식 설명은 회전·실 풀기·같은 색 그룹·그림 공개를 확인해 주지만, 내부 알고리즘까지 공개하지 않는다. [G1, G2, A1, O1]

**완전한 역설계를 완료했다고 주장하지 않는다.** 공개 이미지와 리뷰는 직접 읽고 비교했다. YouTube에서는 제목·길이·레벨별 목록을 확인했지만, 두 제작자의 동영상이 브라우저에서 0:00에 정지했다. 따라서 실제로 관찰한 재생 구간은 0개다. 레벨 117을 언급하는 자료는 찾았지만 중후반 연속 플레이를 검증하지 못했다. 아래 미확인 사항을 임의의 원작 사실로 바꾸지 않는다.

요청한 문서는 모두 제공하되, 02~09의 수치와 알고리즘은 **우리 게임의 독자적 후보 사양**이다. 특히 원작의 3개 매치, 기본 스풀 수, blocker 판정은 영상 검증 전 원작과 동일하다고 확정하지 않는다. 08·09에 해당 검증 게이트를 넣었다. 이번 작업에서는 APK·코드·모델·텍스처·레벨 파일을 취득하거나 게임을 개발하지 않았다.

## 5. 내부 상태를 설명하는 가장 작은 가설

아래는 관찰과 일관되는 추상 모델이며, 원작 코드를 복원한 것이 아니다.

| 개념 | 필요한 상태 | 아직 확정하지 못한 부분 |
|---|---|---|
| YarnPiece | board / transferring / buffered / collected, color, selectable | 한 클릭이 한 묶음인지 연속 strand인지; 가변 실 길이가 수집량에 영향을 주는지 |
| Layer | 어떤 조각보다 바깥에 있는가 | 전역 층인지 부품별 부분 순서인지 |
| Occlusion | 현재 시점에서 hit 가능 | 논리 blocker와 시각적 가림의 대응 |
| Support/Block | 실을 가진 지지 조형 | 실 제거 후 조형이 떨어지는 정확한 조건 |
| Spool | 요구색, 진행량, complete 상태 | 수용량 3 여부, 동일색 스풀 중 배정 우선순위 |
| Buffer | 용량, 점유 색 | FIFO인지 자유 재배정인지, 자동 이동 시점 |
| Match | 요구량 충족 | 3개 단위인지 실 양인지, 상자 단위인지 |
| Reveal | 그림 진행도 | 색 구역과 조각 수의 정확한 대응 |

후보 전이: 선택 요청 → 접근성 판단 → 수집/보관 경로 판단 → 실 제거·이동 → 스풀 진행 → 완성 스풀 교체 → 대기 실 재배정 → 그림 진행 → 승리/막힘 검사. **어느 단계가 먼저인지는 원작에서 미검증**이다. 우리 버전은 02에서 이 순서를 결정적으로 정의한다.

### 3D와 blocking

외형상 앞에 있는 모든 물체를 blocker로 볼 수 없다. 모델을 돌려 뒷면에서 잡을 수도 있기 때문이다. 반대로 일부가 보인다고 제거 가능한 것도 아니다. 실 끝이나 지지 구조가 잠겨 있을 수 있다. 다음 네 가설을 구분해야 한다.

1. 화면의 첫 raycast hit만 선택 가능한 방식.
2. 실별 authored blocker 목록이 있는 방식.
3. 지지판에 남은 실/핀을 제거하면 판이 사라지고 아래 조각이 열리는 방식.
4. 특정 인출 방향을 검사하는 방식.

현재 자료는 이 중 하나를 배타적으로 확정하지 못한다. 우리 버전은 **명시적인 blocker graph + 실제 화면 hit 검사**를 사용한다. 단, 그래프와 외형의 불일치를 별도 검증한다.

### 불공정성 판정

확인한 사실은 광고로 도움을 얻는 구조와, 원하는 스풀 색이 나오지 않아 막힌다는 반복적인 사용자 경험이다. **의도적 해답 없음, 플레이 중 색 조작, 광고 시청 후 seed 변경은 증명되지 않았다.** 광고 유도 의도와 수학적 불가능성은 리뷰만으로 판정할 수 없다. 대안 원인에는 나쁜 무작위 큐, 매우 좁은 해답, 정보 부족, 선택 실수, 버전별 오류가 모두 있다.

독자 버전에서는 동기를 추측해 복제하지 않고, 기본 2수집대·5보관칸만으로 풀리는 해답 증명서를 레벨에 붙인다. 플레이 중 요구색을 몰래 바꾸지 않고 재시작도 동일 상태로 한다. 이것은 “어떤 선택을 해도 승리”를 보장한다는 뜻은 아니다. 실수로 막힌 경우는 무료 undo로 회복한다.

## 6. 초반·중반·후반: 확인 가능한 것과 없는 것

원작이 공식적으로 초/중/후반을 나눴다는 근거는 없다. 여기서는 조사 편의를 위해 1~20 / 21~200 / 201+로 분류한다.

| 구간 | 확인 가능한 증거 | 개수·층·기믹에 관한 결론 |
|---|---|---|
| 초반 1~20 | 레벨 1,2,3 개별 영상과 2~12 플레이리스트 존재. L4에서 남은 조각 4~5개가 걸린다는 리뷰 | 총 실 수·색 수·layer 수·기본 슬롯 변화 모두 직접 계수 미완료 |
| 중반 21~200 | 117을 언급한 영상. 158~164 인간형, 170대 패턴 반복이라는 Android 경험담 | 인간형 반복 보고는 확보. 신규 기믹/숫자별 모델 매핑은 미확정 |
| 후반 201+ | 324 색 구별/5핀 rack, 509 도감 210 정지, 555 반복, 696 반복, 1400+ 도움 의존, 2000 광고 보고 | 장기 플레이 후 반복/광고 불만은 교차 확인. 실 수·색 수·층 증가를 수치화할 영상은 미확보 |

스크린샷에는 동물형, 얼굴/인간형, 음식, 생활 사물, 기하학적 뭉치, 복합 구조가 보인다. 이것을 레벨 번호에 대응시키지 않는다. 큰 오브젝트가 항상 더 어려운지도 미확인이다. 원작의 증가 패턴을 “후반 120개 실·8색·5층” 같은 숫자로 만들어 쓰지 않는다.
