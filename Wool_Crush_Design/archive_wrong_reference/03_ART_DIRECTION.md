# 독자적인 털실 아트 방향

2026-09-08 · Art Bible v0.9 · 원작 관찰과 자체 목표를 분리

## 1. 목표

같은 장르에 놓아도 초라하지 않은, 손에 쥐어 보고 싶은 작은 털실 장난감을 만든다. 원작의 포근함은 막연한 파스텔색이 아니라 **굵은 감김 홈, 둥근 덩어리, 선명한 색 구획, 작은 매듭, 부드러운 명암**의 조합으로 읽힌다. [01의 I01~I18]

원작의 개별 동물·음식·얼굴 비례와 색 배치를 그대로 다시 만들지 않는다. “실 소재만 공유하는 전혀 다른 화풍”으로 도망가지도 않는다. 감김 밀도, 곡면의 부드러움, 색의 읽힘, 조명의 대비, 선택 피드백은 적극적으로 참고한다.

가제는 **포근한 실방**이다. 이름·아이콘은 임시이며 원작 로고나 캐릭터에 의존하지 않는다.

## 2. 원작 Art Breakdown

| 항목 | 이미지에서 관찰됨 | 구현에 대한 추정 |
|---|---|---|
| 큰 형태 | 상자·구·원통·둥근 판을 조합한 장난감 비례 | 단순 base mesh와 부품 조합으로 충분할 가능성 |
| 실 표면 | 평행하거나 감기는 굵은 홈, 꼬임처럼 보이는 미세 음영 | 튜브/곡선 + normal 혼합 가능. 사진만으로 실제 strand 수 판별 불가 |
| 실 묶음 | 동그란 매듭 또는 작은 감긴 뭉치가 색상 선택점을 만듦 | 선택용 별도 mesh/prefab 가능 |
| 층 | 평평한 띠·판·삼각 조각이 아래 구조를 가리는 장면 | 모든 층이 물리적인 한 가닥의 끈일 필요는 없음 |
| 재질 | 넓고 부드러운 하이라이트, 홈 안의 짙은 음영 | 높은 roughness, AO, normal 기여 가능 |
| 잔털 | 모든 화면에서 개별 fuzz가 또렷하게 보이지 않음 | 실제 수천 가닥 hair 렌더라고 단정 불가 |
| 색 | 노랑·분홍·민트·파랑 등 뚜렷한 면 분리 | 값싼 채도 저하보다 조명 아래 색 차이 관리가 중요 |
| 조명 | 비교적 밝은 환경, 부드러운 그림자 | ambient와 넓은 광원 느낌을 조합했을 가능성 |
| 카메라 | 전체 형태를 쉽게 읽는 3분면 시점, 원근 압축 느낌 | orthographic 또는 긴 초점거리 perspective 둘 다 가능 |
| 실 당김 | 실뭉치에서 스풀로 이어지는 부드러운 곡선 | spline 인출 가능; 시간 프로파일 미확인 |

금속성 0, roughness 0.85, FOV 30° 같은 수치를 원작 측정값으로 부르지 않는다. 스크린샷은 홍보용 문구/배치가 있으므로 실제 UI 비율의 정밀 계측 자료로 삼지 않는다.

## 3. 우리 조형 규칙

### 세 단계 디테일

1. **2초에 읽히는 silhouette:** 작은 화면에서도 동물/사물의 종류가 보인다.
2. **한눈에 보이는 감김:** 개별 굵은 실의 홈이 기본 플레이 거리에서 살아 있다.
3. **확대할 때 느끼는 섬유:** 꼬임과 미세 섬유 음영이 나타난다. 기본 화면에서 자글거리는 노이즈는 금지한다.

외형의 핵심 굴곡은 geometry로 만든다. 몸통에 털실 normal만 입혀 매끈한 풍선처럼 보이면 불합격이다. 반대로 모든 미세 섬유를 실제 튜브로 만들 필요는 없다.

### 독자 비례와 디테일

| 항목 | 시작 기준 |
|---|---|
| 동물형 머리 | 높이의 약 35~45%, 하나의 실루엣으로 읽히게 |
| 눈/표정 | 작고 단순한 바느질 표정. 게임용 색상 선택점과 구별 |
| 손발/부리/꼬리 | 가느다란 바늘형 대신 짧고 둥근 부품 |
| 모서리 | 화면에서 각진 톱니가 남지 않도록 bevel/곡면 처리 |
| 실 지름 | 몸통 대표 폭의 1~2.5% 범위로 시도. 작은 부품에는 상한/하한 clamp |
| 실 간격 | 중심선 간 1.05~1.2 지름을 시작값으로; 홈은 남기되 속이 빈 골조처럼 보이지 않게 |
| 선택 뭉치 | 주변 장식보다 식별 쉬운 크기, 같은 색 기호를 작은 태그에 병기 |
| 겹침 | 차단하는 쪽이 어디인지 노출된 가장자리와 약한 그림자로 읽힘 |

위 값은 우리 시제품의 실험값이다. 눈·입 같은 장식은 논리 piece와 분리하되, 장식이 선택 대상을 가리지 않게 한다.

## 4. 팔레트와 가독성

첫 12개 모델은 아래 6색을 중심으로 만든다. 한 레벨에 모든 색을 강제로 넣지 않는다.

| ColorId | 기준 sRGB | 보조 기호 | 역할 |
|---|---|---|---|
| coral | #E97778 | 원 | 따뜻한 주색 |
| honey | #E5B94A | 삼각 | 밝은 주색 |
| mint | #67B79E | 잎 | 중간 명도 녹색 |
| sky | #69AEE0 | 물방울 | 밝은 파랑 |
| plum | #9464AF | 마름모 | 어두운 보라 |
| cream | #E8D9BB | 별 | 부드러운 밝은 중립 |

이 팔레트가 색각 이상에 안전하다고 인증하지 않는다. 실제 shader·조명·밝기 30/70/100%·색각 시뮬레이션에서 확인한다. 색만으로 구별시키지 않고 묶음, 스풀, 보관칸 모두에 같은 기호를 사용한다. 그림의 장식색은 논리 ColorId와 분리해도 되지만, 수집되는 실 자체의 색은 일치해야 한다.

선택 가능 표시 때문에 본래 색을 다른 색으로 바꾸지 않는다. 잠긴 조각은 원색을 유지하고 약한 음영/작은 차단 표시로 표현한다. 강한 흰색 rim이나 emission으로 파랑과 보라가 같은 색으로 보이면 실패다.

## 5. 재질과 조명 목표

| 요소 | 우리 시작값/방향 | 실패 징후 |
|---|---|---|
| base color | 색표 기준, 섬유 길이 방향의 작은 명도 변동 | 얼룩·강한 흰 반사 |
| metallic | 0 | 금속/비닐 느낌 |
| roughness | 0.75~0.9 실험; URP smoothness는 대략 0.1~0.25부터 | 젤리처럼 반짝임 |
| normal | 실 방향과 맞는 꼬임, 미세 섬유 강도는 낮게 | 고무 골판/지글거림 |
| AO | 접합부·감김 홈 위주 | 까만 먼지선·제거 뒤 남은 유령 그림자 |
| fuzz/Fresnel | 아주 약한 grazing 밝기, 확대 때만 선택적 fiber card | 백색 외곽선·솜사탕 덩어리 |
| anisotropy | MVP 필수 아님. 방향성 하이라이트가 필요할 때만 비용 비교 | 실이 금속 케이블처럼 보임 |
| subsurface 느낌 | 약한 따뜻한 wrap lighting으로 우선 구현 | 밀랍/반투명 플라스틱 |
| key light | 화면 좌상단, 약 35~50° 고도 | 딱딱한 검은 투영 그림자 |
| ambient | 중립~미세하게 따뜻한 밝은 환경 | 채도가 씻기거나 면 구별 소실 |
| 그림자 | 바닥 contact와 부품 겹침에 집중 | 그림자 없는 공중 스티커 느낌 |
| post | 선명도 유지, 과한 bloom/DOF/필름 그레인 없음 | 색 변형·선택점 흐림 |

색 온도를 정확한 켈빈으로 원작에 대응시키지 않는다. 우리 룩에서는 key를 약간 따뜻하게 하고 ambient는 중립으로 두는 정도로 시작한다. 노출은 고정하고 자동 노출을 쓰지 않는다.

## 6. 화면과 카메라

실제 게임 화면은 세로 기준 상단 10~12% 상태/작품 미리보기, 다음 14~18% 수집·보관, 중앙 약 58~64% 조형 조작, 하단 10~12% 도구를 목표로 한다. 비율 합계는 디바이스 safe area를 뺀 실제 공간에 맞춰 조정하며 서로 겹치게 쌓지 않는다. 원작 화면 비율을 측정한 수치가 아니다.

완성 그림은 플레이 중 작은 미리보기로 접고, 눌렀을 때만 감상한다. 수집할 때 미리보기 한 구역이 짧게 채워지는 것을 보여 준다. 작품이 조형 위로 떨어지거나 선택점을 덮지 않게 한다.

카메라는 **perspective 수직 FOV 30°**를 1차안, orthographic을 비교안으로 둔다. 초기 yaw 약 25°, pitch 약 20°에서 조형마다 silhouette이 가장 명확한 자세를 authoring한다. 거리/ortho size는 pixel framing으로 계산한다. 모델별 눈대중 거리 숫자를 수십 곳에 흩뿌리지 않는다.

회전 pivot은 모델 원점과 별개이며 남은 조각 bounds를 기준으로 갱신한다. 확대는 pinch 중심 근처를 유지하고 UI 뒤까지 모델을 밀어 넣지 못하게 제한한다. 원작 리뷰에서 확인된 고정 중심 문제를 재현할 필요는 없다. [G2,A2]

## 7. 촉각적 애니메이션 방향

| 순간 | 감각 목표 | 구현 분류 / 후보 시간 |
|---|---|---|
| 선택 | 작은 탄성, 누름이 즉시 느껴짐 | scale/offset tween, 60~90ms |
| 당김 시작 | 끝이 먼저 팽팽해짐 | spline endpoint, 80~120ms |
| 풀림 | 감긴 실이 끝에서 차례로 줄어듦 | arc-length trim + 이동 spline, 300~600ms |
| 스풀 감김 | 속도와 감기는 양이 연결됨 | 회전·반지름/감김 mesh 증가, 풀림과 동기화 |
| 같은 색 완료 | 한 묶음이 정리됐다는 짧은 확인 | tween+작은 sparkle, 140~220ms |
| 부품 제거 | 가볍게 내려앉아 사라짐 | authored transform tween, 180~300ms |
| 그림 공개 | 구역이 실로 채워지는 느낌 | 마스크 sweep, 180~300ms |
| 레벨 완료 | 조용한 자랑, 바로 다음으로 갈 수 있음 | 0.8~1.2초 감상, 즉시 skip 가능 |

원작 영상 타이밍을 측정한 수치가 아니다. 일반 scale tween만으로 “실이 풀린다”를 대체하면 안 된다. 해체 중 남은 감김과 뻗는 실의 끝점이 연결되어야 한다. 실제 로프 물리·전체 메시 소프트바디는 목표가 아니다.

## 8. 독자 콘텐츠 계획

| 카테고리 | 독자 모티브 후보 | 형상 생성 기반 |
|---|---|---|
| 동물 | 도토리 주머니 수달, 작은 귀의 졸린 알파카 | 타원 몸통+짧은 appendage |
| 음식 | 배 모양 찻잔 푸딩, 접힌 와플 보트 | 회전체+접힌 판 |
| 생활용품 | 둥근 우편함, 발 달린 작은 물뿌리개 | bevel box+관/손잡이 |
| 장난감 | 별 돛의 당김 배, 단추 바퀴 기차 | 판+원통 조합 |
| 식물 | 곱슬 잎 고사리 화분, 버섯 우산 정원 | 줄기 curve+잎 fan |
| 탈것 | 구름 배달 세발차, 조약돌 잠수정 | capsule+바퀴/핀 |
| 판타지 | 찻잎 귀 작은 정령, 달 주머니 생물 | 단순 비대칭 덩어리 |
| 계절 | 솔방울 랜턴, 눈꽃 장갑 집 | 기존 문법+새 silhouette |

이름만 바꾸고 기존 모델의 눈·귀·무늬·배치를 복제하지 않는다. 첫 콘텐츠 12개는 서로 다른 silhouette이어야 한다. 색만 바꾼 모델을 신규 수집품으로 세지 않는다. 같은 motif 재도전은 별도의 변주로 표시한다.

## 9. 아트 승인 방식

첫 검증 대상은 **둥근 생물 / 손잡이 있는 사물 / 얇고 넓은 잎** 세 가지다. 단순 구 하나가 예쁘다는 이유로 자동 변환 성공을 선언하지 않는다.

고정된 조명·카메라·폰 해상도에서 정면, 3분면, 측면, 확대, 중간 제거 상태를 비교한다. 원작 스크린샷과 우리 이미지의 조형 크기를 비슷하게 맞춰 평가하되 픽셀 동일성 점수를 쓰지 않는다.

| 평가 | 0~4점의 4점 기준 |
|---|---|
| 포근함 | 플라스틱보다 감긴 실로 즉시 읽힘 |
| 감김 | 기본 거리에서도 방향·두께·홈이 분명 |
| 귀여움 | 실루엣과 표정이 수집 욕구를 만듦 |
| 색 가독성 | 조명/선택 상태에도 ColorId 구별 가능 |
| 풀림 | 끝점 연속·속도감·감김 감소가 자연스러움 |
| 모바일 완성도 | 가장자리·그림자·잔떨림이 거슬리지 않음 |

모든 항목 3점 이상, 포근함·풀림·가독성은 4점 목표. 이것은 내부 품질 게이트이지 객관적 원작 동등성 증명은 아니다. 아내의 직접 플레이 평가가 최종 취향 검증이다. 평가는 실물 폰의 플레이 가능한 시제품으로 하며 홍보용 렌더만으로 통과시키지 않는다.
