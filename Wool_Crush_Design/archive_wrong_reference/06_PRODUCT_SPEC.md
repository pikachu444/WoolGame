# 광고와 과금 없는 개인용 게임 제품 사양

작업명: **포근한 실방**. 공개 배포 이름이나 상표 사용 가능성을 조사한 이름은 아니다. 우선 한 사람을 위해 만드는 완전 오프라인 Android 게임이다.

## 1. 제품의 성공 조건

아내가 귀여운 털실 조형을 보고 만져 보고 싶어야 한다. 실을 풀어 스풀에 감는 반응이 만족스러워야 하고, 보관 공간과 제거 순서를 생각할 이유가 있어야 한다. 광고·구매·시간 제한 때문에 놀이가 끊기지 않아야 한다.

성공은 설치 수나 체류 시간이 아니라 실제 사용자가 자발적으로 다음 조형을 열고 싶어 하는가로 판단한다. 익명 분석 SDK도 넣지 않는다. 제작자가 옆에서 관찰하거나 사용자가 말해 준 의견으로 개선한다.

| 항목 | 결정 |

| 네트워크 | 모든 레벨·도감·저장·음향 로컬. 플레이에 서버 불필요 |
| 계정 | 로그인·프로필·친구·랭킹 없음 |

## 3. 반드시 제거할 상업 장치

광고 SDK, rewarded/interstitial/banner/forced ads, 광고로 슬롯 늘리기, 구매 복구, IAP SDK, 코인 판매, 구독, 가챠, 배틀패스, 온라인 분석 SDK를 프로젝트 의존성에 넣지 않는다. 광고 제거 버튼도 존재하지 않는다. 부스터 재화와 상점 화면을 새로 만들 이유가 없다.

표준 모드에서 풀리지 않는 초기 상태를 배포하지 않는다. 현재 주문과 먼 색을 요구하는 공간 관리 문제는 가능하지만, 광고 보상을 받아야만 해답이 생기도록 용량을 줄이지 않는다. 도움을 써도 완료 보상과 도감 품질은 같다.

레벨 완료 시 다음 레벨과 해당 모델의 감상 상태를 연다. 같은 모델의 변형 레벨 완료를 새로운 모델 획득으로 과장하지 않는다.

## 4. 화면과 흐름

| 화면 | 핵심 내용 | 행동 |
|---|---|---|
| 시작 | 계속하기, 레벨 선택, 도감, 설정 | 저장된 플레이로 한 번에 복귀 |
| 레벨 선택 | 순서·모델 미리보기·완료 상태 | 완료 레벨 재플레이, 다음 기본 레벨 |
| 플레이 | 상단 주문, 접을 수 있는 작은 완성 그림, 중앙 조형, 보관대, 하단 도움 | 회전·선택·undo·힌트·재시작 |
| 막힘 | ‘몇 수 되돌리면 이어갈 수 있어요’ | undo, 힌트, 편안하게, 재시작 |
| 완료 | 완성 그림, 짧은 칭찬 문구, 조형 감상, 다음 | 자동 광고·자동 다음 레벨 없음 |
| 도감 | 원래의 완전한 털실 조형 | 회전·확대·테마별 감상 |
| 설정 | 음향·진동·모션·색 구분·난이도·그래픽 | 즉시 적용, 의미 있는 항목만 |

플레이 화면은 광고가 사라진 공간을 조형과 손가락 조작에 돌려준다. 수집 그림을 위쪽 절반 크기로 유지할 필요가 없다. 기본은 작게, 완료 순간에는 크게 보여 준다. 조형의 남은 bounds를 따라 회전 중심을 부드럽게 갱신하고 재중앙화 버튼을 제공한다. 카메라가 자동으로 갑자기 돌아가지는 않는다.

## 5. 도움 기능의 역할

- **Undo:** 마지막 유효 선택의 전체 연쇄 결과를 되돌린다. 실 하나만 되살리고 주문·그림 상태를 남기는 부분 복구는 금지한다.
- **힌트:** 다음에 풀 수 있는 안전한 조각과 잘 보이는 시점을 보여 준다. 사용자가 직접 누르게 한다. 계산 중에는 상태를 확정적으로 평가하지 않는다.
- **편안하게:** 현재 레벨을 더 넓은 보관/수집 조건으로 이어 간다. 변경 자체도 snapshot으로 남겨 되돌릴 수 있다. 표준 복귀는 재시작 또는 다음 레벨에서만 선택한다.
- **재시작:** 같은 seed·색·주문·형태로 다시 한다. 실패할 때 새로 섞여 학습이 무효가 되지 않는다.

무제한 undo가 퍼즐 재미를 없애는지 실제 플레이로 확인한다. 기본 해답을 자동으로 보장하는 선택 제한은 넣지 않는다. 틀릴 수 있으나 복구에 벌이 없는 구성을 우선한다.

## 6. 카메라와 접근성

손가락 드래그는 회전, 두 손가락은 확대/이동으로 분리한다. 터치 시작점이 UI이면 모델 조작으로 넘기지 않는다. 탭·드래그 판정은 화면 픽셀 대신 기기 밀도를 고려한 단위로 처리한다. 자세한 시작값은 02·03을 따른다.

색 이름이나 RGB만으로 정보를 전달하지 않는다. 색 구분 모드에서는 스풀에 심벌을 붙이고 해당 실의 끝/선택 강조에도 같은 심벌을 제공한다. 전체 실 표면에 고대비 패턴을 강제로 넣어 포근함을 해치지 않도록 한다. 비슷한 밝기의 색은 같은 작은 영역에서 겹치지 않게 palette 검증을 한다.

시스템 글자 크기 변화와 화면 safe area를 점검한다. 주요 버튼은 약 48dp 이상의 터치 영역을 출발점으로 삼되 최종 수치는 실제 사용에서 확인한다. 색 구분 기능이 의학적 접근성 인증을 받았다는 표현은 하지 않는다.

‘움직임 줄이기’는 화면 흔들림·과한 튐·긴 축하 효과를 줄이고 실의 이동 방향은 남긴다. 줌 과속·회전 관성을 낮추는 옵션을 제공한다. 빠른 점멸이나 선택 실패 때 큰 화면 충격은 사용하지 않는다.

## 7. 음향과 촉각

원작 사운드를 사용하지 않는다. 짧은 부드러운 마찰, 나무 스풀의 작은 접촉음, 음정이 조금 올라가는 완료음을 직접 합성하거나 출처가 확인된 허용 자산으로 만든다. 작은 소리 여러 개가 동시에 커지지 않도록 voice 수와 peak를 제한한다.

음악·효과음·진동을 각각 끌 수 있다. 초기 버전은 긴 배경음악보다 잘 만든 소수 효과음을 우선한다. 진동은 선택과 수집 완료에 약하게 사용하고 지원하지 않는 기기에서는 조용히 생략한다. Android의 외부 음악 앱과 함께 재생하는 상황을 실제 기기에서 검사한다. 원작에 외부 소리가 멈춘다는 보고가 있으므로 기본값으로 오디오 독점을 강제하지 않는다. [R18,R21,R33; 01 리뷰 로그]

## 8. 저장·중단·복구

논리 move가 확정될 때 저장한다. 애니메이션 도중 앱이 중단돼도 결과는 한 번만 적용된다. 임시 파일 작성 후 교체하는 방식과 이전 정상 저장본 1개를 사용한다. 실제 모바일 파일시스템에서 오류 처리를 검증한다.

저장 내용은 schemaVersion, rulesetVersion, levelHash, 현재 논리 상태, undo history, 모드, 완료 레벨, 도감, 설정이다. 광고 ID·계정·위치·연락처를 저장하지 않는다. 카메라 자세는 별도로 저장해 논리 undo와 충돌하지 않게 한다.

손상된 저장은 이전 정상본으로 복구를 시도하고, 불가능하면 해당 레벨 재시작을 제시한다. 전체 도감을 조용히 삭제하지 않는다. 새 콘텐츠에서 기존 levelHash가 바뀌면 이미 진행 중인 원본 revision을 유지하거나 명시적인 migration을 제공한다.

첫 배포는 로컬 저장만 구현한다. 후속 버전의 수동 내보내기/가져오기는 Android 문서 선택기를 통한 사용자의 파일 선택으로 제한할 수 있다. 이때 다른 게임 자산이나 원작 파일을 읽을 필요는 없다.

## 9. 오프라인의 검증 가능한 정의

최종 APK의 merged manifest와 패키지 목록을 검사하고, 광고·분석·결제 라이브러리가 없는지 확인한다. release 빌드에서 네트워크 권한을 제거할 수 있도록 의존성을 구성한다. 디버그 연결 기능이 release에 남지 않게 한다. 권한 검사만으로 오프라인을 증명하지 않고 비행기 모드에서 설치 후 실행·전체 진행·앱 재시작·도감·도움을 확인한다.

게임 실행에 로그인은 없다. Unity 설치·라이선스 활성화·패키지 다운로드 같은 **개발 환경의 최초 준비**는 별개의 작업이다. 개발 도구의 온라인 준비가 게임의 서버 의존성이 되어서는 안 된다.

## 10. 수용 기준

| 영역 | 통과 기준 |
|---|---|
| 퍼즐 | 모든 배포 레벨이 기본 2/5/3으로 SAT, 인증 해답을 정식 Core로 재생 성공 |
| 아트 | 03의 실루엣·표면·빛·색·풀림·가독성 평가 각 3/4 이상; 원작 공개 이미지와 나란히 검토 |
| 조작 | 정상 해답의 모든 조각을 회전/확대로 보고 누를 수 있음 |
| 복구 | 연쇄 완료 중 undo, 중단 후 복귀, 동일 레벨 재시작이 상태를 보존 |
| 성능 | 04의 임시 예산을 실제 기기 결과로 교정하고 목표 등급 달성 |
| 즐거움 | 실제 사용자에게 시각 품질·반복감·어려움·촉각감을 별도로 질문하고 관찰 |
| 독립성 | 비행기 모드에서 필수 흐름 완주, 광고/결제/분석 의존성 없음 |

사용자가 ‘그림체가 평범하다’고 느끼면 레벨 수가 많아도 통과가 아니다. 그 경우 콘텐츠 확장을 멈추고 재질·감기·조명·비율을 다시 조정한다.

## 근거

긍정 요소와 유지 이유, 광고·카메라·색·반복·성능 불만은 [01_REFERENCE_GAME_ANALYSIS.md](01_REFERENCE_GAME_ANALYSIS.md)의 40개 리뷰 코딩과 원문 링크를 따른다. 이 문서의 해결책은 해당 리뷰가 효과를 입증한 방법이 아니라, 우리 제품에서 검증할 설계 결정이다.
